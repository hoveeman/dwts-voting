# DWTS Voting — Legacy Shortcut Manifest Bridge

This repository serves as a permanent backward-compatibility bridge for Trent's **DWTS Voting** iOS Shortcut (v1.5 and v1.6).

The official master repository and native application development has moved to:
👉 **[hoverstonellc/ballroom-companion](https://github.com/hoverstonellc/ballroom-companion)**

### Endpoints Preserved for Shortcuts:
- `dancers.json` (Live active dancer roster and v2 keyword mappings)
- `version.json` (Automated update checks)
- `dancers.txt` (Plaintext fallback list)
